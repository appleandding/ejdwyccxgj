小手机 / API 账密双分区存储
在【我的】→【小手机/api账密存储】中，顶部设有【小手机】与【API】两大分区切换：
• 小手机模式：收录小手机名称、登录账号及密码/激活码；
• API 模式：收录 API 站子名称、账号密码、以及专属的 API URL 和 API Key；
• 均支持纯明文免安全键盘输入，每项信息均可一键单独复制。
小手机网页工具图标与修改
• 添加自定义图标：点击【添加】小工具时，顶部方框带有加号，点击即可从相册上传专属正方形图标；
• 长按修改与换图标：长按任意小手机图标弹出液态玻璃弹窗，居中显示当前图标，轻触该图标可即时更换相册图片；弹窗内可直接编辑名称、网址链接及切换绑定的浏览器。
普通人设卡修改与更换头像
• 普通人设：轻触卡片进入详情，顶部方框可随时上传更换人设头像，并支持在线修改人设名称与设定正文；
• 酒馆人设保护：导入的酒馆角色卡保持结构化安全只读，保障角色原设定与正则样式不被破坏，随时可导出原件。
长按标签自定义排版
长按顶部任意标签胶囊（如人设、美化、世界书或自定义标签），可自由在小图标网格、单列长条、一行两个长方形、正方形等排版样式间自由切换。
批量多选与 ZIP 大包自动解压
饭饭与其它分区支持批量多选导入 docx、txt、html、json 文件及 ZIP 压缩大包，系统内嵌解包引擎会自动提取所有有效文件并自动识别归档，同时支持手写直接录入。
